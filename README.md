 Country Explorer CLI
Project Description
Country Explorer is a Python command-line program that uses the countries.dev API to retrieve live country information. The tool enables one to find a country and see such significant information as the capital city, region, population, area, and official languages.The project illustrates the basics of Python such as API requests, processing of JSON data, functions, user input, and error processing.
API Used
This project uses the Countries.dev API:
https://countries.dev/countries
The API provides information about countries around the world, including:
- Country name
- Capital city
- Region
- Population
- Area
- Languages
Features
The application includes:
- Fetching live country data from an external API
- Searching for a country by name
- Processing nested language data
- Displaying formatted country information
- Handling invalid searches and empty input
- Handling API connection errors
